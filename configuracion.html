Formas de pago

Las que ves en la pantalla de Ventas. Cuenta corriente = genera deuda (solo aparece con un cliente elegido). Facturar (ARCA) = a futuro se facturarán automáticamente por AFIP (por ahora solo se guarda la preferencia).

Locales

Nombre, sigla (prefijo de comprobantes), dirección y teléfono. La dirección y el teléfono salen en el ticket. La sigla arma el comprobante (ej. FAB-20260916-0001).

Balanzas

Cómo leer la etiqueta de balanza por local. Prefijo = 2 dígitos que marcan etiqueta de balanza. Dato = si trae peso (kg) o precio ($). CodLen/DatoLen = dígitos del código y del dato.

Categorías de gasto

Cada gasto se imputa a una categoría (detalle), y cada categoría pertenece a un grupo (nivel mayor, ej. Estructura, Carnicería, Almacén). Se guarda al salir del campo.

CategoríaGrupo

Reparto de gastos entre locales

Para las categorías que se reparten, poné el % que asume cada local (idealmente suma 100% por categoría). Vacío = no se reparte. Se guarda al salir de la celda.

Terminales Clover

Por cada local, cargá el Merchant ID y el token de su terminal Clover (Panel Clover → Configuración → API Tokens, con permisos de Leer). El token se guarda en el backend y no vuelve a mostrarse por seguridad; para cambiarlo pegá uno nuevo y Guardá.

Aranceles y plazos por medio de pago

% de descuento y días hábiles hasta el depósito, por medio. Sirve para calcular el neto esperado y la fecha estimada de acreditación en Conciliación. El «Medio» debe coincidir con el nombre de Clover (ej. «Tarjeta de crédito», «Tarjeta de débito», «QR PosNet»).
